# Tintcast

One theme for your whole Windows desktop: wallpaper, light or dark, accent color, terminals, and code editors, in one step. Tintcast shows every change before it makes it, and puts your original setup back when you ask.

Tintcast is in its first phase: the probes in `spike/` check each part of Windows it needs.
